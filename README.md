# MegaHack Geode + Frame Prediction (Click Assist)

Полноценный аналог **Mega Hack** для **Geometry Dash (версия 2.2074+)**, созданный с использованием современного C++ фреймворка **Geode SDK**, дополненный инновационной системой **Frame Prediction (Click Correction / Assist)**.

---

## 🌟 Главная фича: Frame Prediction (Коррекция кадров клика)

### 📌 Как это работает:
В стандартной Geometry Dash, если игрок нажимает прыжок слишком рано:
1. Либо куб прыгает в потолочный шип или не долетает до платформы;
2. Либо в воздухе до сферы (орба) клик сгорает впустую / буферизируется некорректно, из-за чего игрок разбивается.

**Frame Prediction** перехватывает ввод игрока (`GJBaseGameLayer::handleButton`):
1. **Симуляция траектории (Lookahead):** Алгоритм просчитывает физику движения игрока на $N$ кадров вперед (с шагом физического тика GD $1/240$ сек).
2. **Анализ опасности:** Если клик в текущий кадр ($T=0$) приводит к неминуемой смерти о шип (`m_hazardObjects`) или сфера (`m_ringObjects`) ещё не вошла в радиус активации, клик **не сбрасывается**, а ставится в буфер ожидания.
3. **Подводка до безопасного кадра:** На каждом тике физики в пределах заданного окна (`Prediction Window`, настраивается от 1 до 30 кадров) система проверяет безопасность траектории. Как только наступает кадр, где прыжок безопасен или сфера достигнута — клик моментально исполняется!
4. **Визуальный отклик:** В HUD отображается зеленый индикатор: `[Predict: Saved +XF!]` с точным количеством скомпенсированных кадров.

## 🚀 Включенные функции (MegaHack Analog)

| Функция | Описание |
|---|---|
| **Frame Prediction** | Автоматическая задержка и подводка клика до безопасного кадра (настройка 1–30 кадров). |
| **Prediction Strategy** | Выбор режимов: `Hazard Avoidance & Orb Snapping`, `Orb Snapping Only`, `Hazard Avoidance Only`. |
| **In-Game Hack Menu** | Открытие меню читов по нажатию клавиши **Tab**, кнопки **MH** в главном меню или в меню паузы. |
| **Noclip** | Отключение урона от шипов и препятствий. |
| **Speedhack** | Изменение скорости игры (от 0.1x до 5.0x) с шагом регулировки. |
| **Practice Music Hack** | Сохранение трека уровня в режиме практики вместо стандартной мелодии практики. |
| **Accurate Percentage** | Отображение точного прогресса уровня с сотыми долями процента (например, `94.62%`). |
| **CPS & Jump Counter** | Счетчик кликов в секунду (CPS) за скользящее окно в 1 секунду и общее количество прыжков. |
| **Safe Mode** | Защита от бана: блокирует отправку рекордов на сервера, если включены читы. |

## 🛠 Сборка и установка

### Требования:
- Установленный [Geode CLI](https://docs.geode-sdk.org/)
- Компилятор C++20 (MSVC на Windows / Clang на Mac/Android)
- Geometry Dash 2.2074+ с установленным Geode Loader

### Команды для сборки:
```powershell
# 1. Перейдите в папку проекта
cd C:\Users\Maks\.gemini\antigravity\scratch\mega-geode-hack

# 2. Настройте проект через Geode CLI
geode build

# 3. Или упакуйте готовый .geode файл
geode package
```

Собранный `.geode` файл автоматически копируется в папку модов игры:
`Geometry Dash/geode/mods/antigravity.megahack_assistant.geode`.

## 🎮 Управление в игре
- Нажмите **`Tab`** во время игры или в меню, чтобы открыть панель **MegaHack**.
- Также кнопка **MH** доступна в нижнем меню главного экрана и в меню паузы любого уровня.
- Кнопками `+` и `-` возле **Frame Prediction** можно на лету регулировать запас кадров (например, выставить `3 frames` для легкой помощи или `10 frames` для широкого окна коррекции).
